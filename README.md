## 📌 Featured Projects

### 🪨 PulsePebble
**Handheld Physiological Monitoring & Guided-Regulation Device**

A self-directed embedded systems project built around an **ESP32-S3** that combines physiological sensing, real-time detection logic, multimodal feedback, and a Python/Flask monitoring interface.

#### What I built

- Integrated **MAX30102** heart-rate sensing and **GSR** measurement
- Designed a **dual-signal detection model** using heart rate + skin conductance
- Implemented a **4-state firmware pipeline:** `NORMAL → PREALERT → ALERT → RECOVERY`
- Added confirmation and stability windows to reduce false transitions
- Built synchronized **LED + vibration box-breathing guidance**
- Added audio escalation for prolonged alerts
- Integrated a **Peltier-based thermal feedback system** for recovery
- Developed a **real-time Flask dashboard** for telemetry, system monitoring, and manual state testing
- Added simulated sensor inputs alongside live serial hardware data for development and demonstrations
- Designed a custom **pebble-shaped enclosure in Onshape**, with sensor contact points integrated into the natural hand grip

The V1 prioritizes rapid hardware iteration using a breadboard-based architecture, with PCB integration and battery operation planned as future revisions.

**Stack:** `ESP32-S3` `MAX30102` `GSR` `WS2812B` `Python` `Flask` `Embedded C++` `Onshape`

Embedded hardware research through the **UW SEAL / Mamishev Lab**, investigating extremely low-frequency electromagnetic signals for applications including atmospheric and ionospheric monitoring.
